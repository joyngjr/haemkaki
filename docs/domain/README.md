# Domain reference

Haemophilia reference material for the HaemKaki team and for the
`haemkaki-domain-expert` agent skill, which reads from and writes new summaries
to this folder. These are clinical references for data modelling and copy, not
prescribing protocols. Check anything here with a clinician before it drives
app behaviour.

| File                                   | What it is                                                               |
| -------------------------------------- | ------------------------------------------------------------------------ |
| `haemophilia-clinical-domain-guide.md` | Comprehensive clinical domain guide, reviewed by the domain expert skill |
| `haemophilia-medication-list.md`       | Prophylaxis, on-demand and adjunct medicines                             |
| `drug-allergies.md`                    | Commonly implicated medicines, used for the drug-allergy search terms    |
| `wfh-guidelines.md`                    | WFH Guidelines for the Management of Hemophilia, 3rd edition (source)    |
